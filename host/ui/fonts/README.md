# Fonts

`fa-solid-900.ttf` is Font Awesome 5 Free Solid, by Fonticons, Inc.
(https://fontawesome.com), under the SIL Open Font License 1.1
(https://fontawesome.com/license/free). It's the font LVGL builds the device's
symbols from (`lvgl/scripts/built_in_font/FontAwesome5-Solid+Brands+Regular.woff`,
which is TrueType despite its name), so the settings window shows the same
icons as the deck.
